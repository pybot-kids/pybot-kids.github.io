LOOK FIRST

Three things to know about in.

in

in looks in a list

"apple" in bag is True when "apple" is one of the things in the bag list.

abc

in looks in text too

"a" in "banana" is True. Capitals matter: "B" in "banana" is False.

not in

not in: is it missing?

not in gives the opposite answer. It is True when the thing is not there.

A trick: in is like a pair of hands searching a box. Found it: True. Not there: False.

STEP BY STEP

How Python searches.

Python checks each thing in the list, one by one.

bag = ["book", "apple", "pencil"]A list with three things.
"apple" in bagbook? No. apple? Yes! Python answers True.
"ball" in bagPython checks all three. No ball, so False.
"ball" not in bagnot in flips it: the ball is missing, so True.
