MADE POSSIBLE BY

Thank you, Pyodide!

Every time you press Run Python, real Python runs right inside your browser. That magic comes from Pyodide, a free, open-source project built by many kind people around the world. Without it, PyBot could not let you code without installing anything.

For grown-ups: Pyodide brings CPython to the browser with WebAssembly. It was created in 2018 by Michael Droettboom at Mozilla and is now an independent, community-driven project under the Mozilla Public License 2.0. PyBot is not affiliated with Pyodide.
