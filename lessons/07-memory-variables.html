FIRST: COMPUTER MEMORY

Think of a worktable and a drawer.

RAM

Memory is the worktable

RAM keeps the things a program is using now. The table can be cleared when the program or device stops.

▣

Storage is the drawer

Files and saved progress can stay for later. They are not the same as the program's working memory.

=

A variable is a labeled spot

robot_color = "orange" puts one value under a useful name.

robot_color="orange"

Use robot_color later, and Python uses the value orange.

THE = SIGN

= puts a value in a box.

Let's go slowly, one small step at a time.

  1. 1

    The box's name goes on the left

    First write the name of the box. Then =. Then what goes inside.

    starsLEFT: the box=5RIGHT: what goes in
  2. 2

    = means "put in"

    Read stars = 5 like this: stars gets 5. Python puts 5 inside the box.

    stars = 5→
    stars5
    Now the box has 5 inside.
  3. 3

    A new = replaces the old value

    A box holds one value. The new value goes in and the old one goes out. = never adds.

    stars = 5→
    stars5
    stars = 8→
    stars58
    The 5 is gone. The box has 8, not 13.
  4. 4

    On the right: a value

    A number or a text in quotes goes straight into the box.

    pet = "cat"→
    pet"cat"
  5. 5

    On the right: an operation

    Python solves the right side first. Only the answer goes into the box.

    total = 3 + 4→7→
    total7
    3 + 4 is 7. The box keeps 7.
  6. 6

    On the right: another box

    Python opens the box on the right, copies its value, and puts the copy in the box on the left.

    stars8
    my_stars = stars→
    my_stars8
    Both boxes have 8 now. stars keeps its 8 too.
