TWO KINDS OF BUGS

Loud bugs and sneaky bugs.

📢

Loud bugs

Python stops and shows an error. Good news: it tells you the line!

print("hi)
🕵️

Sneaky bugs

The code runs, but the result is wrong. Python can't tell. You compare the result with what you wanted.

print(2 + 3) # wanted 2 * 3
💪

Everyone makes bugs

Even the best programmers write bugs every day. A bug is not a failure. It is a clue.

  1. LookWhat did you want? What happened instead?
  2. Read the clueIf Python shows an error, read the last line and the line number.
  3. Fix one thingChange one small thing at a time.
  4. Run againIs the bug gone? If not, back to step 1.
