LOOK FIRST

Key, colon, value.

{ }

Curly brackets

A dictionary goes inside { }. Each pair is key: value. The label is called a key.

🏷️

Find by key

backpack["pencils"] gives back the value with that key.

✏️

Change or add

backpack["pencils"] = 5 changes the value. A new key adds a new pair.

STEP BY STEP

PyBot packs a backpack.

Keys in quotes, values after the colon.

backpack = {"pencils": 3, "books": 2}A dictionary with two keys: pencils keeps 3, books keeps 2.
print(backpack["pencils"])Find by key: shows 3
backpack["pencils"] = 5Change the value: now pencils keeps 5.
backpack["apples"] = 1A new key: apples is added with 1.
print(backpack)Shows {'pencils': 5, 'books': 2, 'apples': 1}
