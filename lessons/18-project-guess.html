THE PLAN

The game in four small steps.

Each step uses something you already know.

1

Hide a secret

Python picks a number from 1 to 10 and keeps it in a box.

random.randint

2

Ask for a guess

Ask the player and turn the answer into a number.

input + int

3

Give a hint

Compare the guess with the secret: higher or lower?

if / elif

4

Repeat and count

Keep asking until the guess is right. Count every try.

while + counter
