WORDS INTO SIGNS

Say it with a sign.

SignIn wordsExampleAnswer
==the same as5 == 5True
!=not the same as5 != 3True
<less than3 < 2False
>more than3 > 2True
<=at most4 <= 4True
>=at least120 >= 130False

A trick: In <= and >=, the = always goes second. >= works, => does not.

STEP BY STEP

Can PyBot ride?

Each comparison gives its own True or False.

height = 125PyBot is 125 cm tall.
height >= 120Is 125 at least 120? True. PyBot can ride.
height >= 130Is 125 at least 130? False. Not the big ride yet.
height == 125Is it exactly 125? True.

LOOK FIRST

Three things to remember.

==

Two = ask

height = 125 fills a box. height == 125 asks a question.

2+3

Math first

2 + 3 == 5: Python does the math, then compares. True.

Aa

Capitals count

"cat" == "cat" is True, but "Cat" == "cat" is False.
