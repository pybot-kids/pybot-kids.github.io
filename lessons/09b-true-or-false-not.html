STEP BY STEP

Mix them together.

Python flips with not first. Then it joins with and or or.

sunny = TrueIt is sunny.
tired = FalsePyBot is not tired.
if sunny and not tired:not tired: flip False into True. Then sunny and True: both are True.
print("to the park!")The answer was True, so this path runs.

LOOK FIRST

Three rules for mixing.

not

not flips one answer

not goes in front of one question and flips only that one.

and

and needs both, or needs one

After flipping, Python joins the answers with and or or.

( )

( ) go first

Python answers what is inside parentheses first. Use them to make a long question clear.
