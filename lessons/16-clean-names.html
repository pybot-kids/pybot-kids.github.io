LOOK FIRST

Three rules for names.

1

Say what it keeps

apples beats a, x or thing. You know what is inside without guessing.

2

Python style

Use lowercase words joined with _, like total_score.

3

Names have rules

No number at the start, no spaces. And score and Score are two different boxes.

LOOK FIRST

Read the names line by line.

Each name tells you what it keeps or what it does.

apples = 5A box called apples. You can tell it keeps apples.
pears = 3Another clear name: pears.
total_fruit = apples + pearsTwo words joined with _. It keeps 8.
def make_juice(fruit):A function name starts with a verb: it says what it does.
