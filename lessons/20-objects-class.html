LOOK FIRST

Three new words, one at a time.

🍪

class

class Robot: starts the mold. Mold names start with a capital letter.

🛠️

__init__

The mold's setup job. It runs by itself each time a new robot is made. Two _ before and two after.

🪞

self

self means “this robot itself”. self.name = name writes the name inside this robot.

STEP BY STEP

Read the mold line by line.

Take it slow. The first 4 lines are only the plan. Line 5 makes a real robot.

class Robot:Starts the mold called Robot. No robot exists yet.
def __init__(self, name):The setup job. It gets the new robot (self) and a name.
self.name = nameWrites the name inside this robot.
self.battery = 100Every new robot starts full: 100.
bolt = Robot("Bolt")Use the mold! Now a real robot exists. You do not write self: Python fills it in.
print(bolt.name)Read its data with a dot: Bolt
print(bolt.battery)Shows 100

Remember the turtle? turtle.Turtle is a mold too. t = turtle.Turtle() used it to make one turtle.
