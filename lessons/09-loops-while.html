07LOOPS · WHILE

Repeat while it is true.

A while loop asks a True-or-False question before every turn. True: one more turn. False: stop.

PYBOT SAYS

LOOK FIRST

while asks before every turn.

?

Ask a question

while battery > 0: asks, is the battery above 0?

↻

True: one more turn

If the answer is True, the indented lines run again.

■

False: stop

If the answer is False, the loop ends and Python goes on.

while battery > 0:321charge me!

STEP BY STEP

Watch the question change.

Something inside the loop must change, so the answer can become False.

battery = 3Start with 3 bars of battery.
while battery > 0:The question. 3 > 0 is True, so a turn starts.
print(battery)Shows what is in the box now: 3, then 2, then 1.
battery = battery - 1Take 1 away. Without this line the answer stays True forever!
print("charge me!")Runs once, when 0 > 0 is False and the loop is over.

LOOK FIRST

for or while?

for

for: you know how many

range(3) gives exactly 3 turns. Use for when you can count the turns first.

?

while: you know when to stop

Keep going until the question becomes False, even if you do not know how many turns.

!

Change the box

If nothing changes, the loop never ends. If that happens, press Stop.
