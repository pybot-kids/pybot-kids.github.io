LOOK FIRST

How input() works.

1

Show the question

The text inside the ( ) is the question Python shows.

2

Wait for Enter

Python stops and waits while the person types and presses Enter.

3

Keep the answer

The answer comes back. Put it in a box with = so you can use it.
