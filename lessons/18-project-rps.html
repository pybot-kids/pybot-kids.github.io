THE PLAN

The game in four steps.

Each step uses something you already know.

1

Your choice

Ask the player and check the word is one of the three options.

input + or

2

PyBot's choice

PyBot picks one word from the list at random.

random.choice

3

Who wins?

A function compares both choices and returns the winner.

def + if/elif + and

4

Best of 3

Repeat 3 rounds and add a point to the winner each time.

for + range + counters
