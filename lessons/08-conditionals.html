06CONDITIONALS

Ask. Then choose.

A conditional lets code choose a path after a yes-or-no question.

if ?else

I check the question before I choose.

LOOK FIRST

You already make choices this way.

if

If asks the question

“Is it raining?” Python checks whether the answer is true.

↳

The indented step is one path

If it is raining, the next step can be: take an umbrella.

else

Else is the other path

If the answer is no, Python can follow a different step.

if raining:
  print("umbrella")take umbrella
OR
else:
  print("cap")wear cap

STEP BY STEP

How Python decides.

Follow the code one line at a time, like PyBot does.

battery = 20A box keeps the number 20.
if battery < 30:Python asks: is 20 less than 30? Yes. The answer is True.
print("charge")True, so this indented line runs.
else:Skipped. The answer was already True.
print("play")Skipped too. Only one path runs.
print("bye")Not indented, so it always runs at the end.
sunny = FalseA yes-or-no box that keeps False.
if sunny:Python asks: is sunny True? No.
print("sunglasses")Skipped. There is no else, so this path just does nothing.
print("let's go")Not indented, so it always runs.

Three rules to remember.

→

Indentation shows the path

Lines pushed right with 4 spaces belong to the path. Lines on the left run no matter what.

:

The colon opens the path

if, elif, and else always end with : right before their path starts.

1

Only one path runs

Python never runs two paths of the same if. It picks one, then keeps going.

MORE THAN TWO PATHS

elif asks one more question.

Python asks from top to bottom and stops at the first True.

temperature = 15A box keeps 15 degrees.
if temperature > 25:Is 15 greater than 25? No. Go to the next question.
print("shorts")Skipped.
elif temperature > 10:Is 15 greater than 10? Yes!
print("jacket")This path runs.
else:Skipped. A path already ran.
print("coat")else runs only when every question was False.
