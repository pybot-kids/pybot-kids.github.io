06TRUE OR FALSE? · OR

or: one is enough.

or joins two questions. The answer is True when at least one answer is True.

PYBOT SAYS

IN REAL LIFE

Sometimes one is enough.

If either thing happens, the answer is yes.

🍰

STEP BY STEP

Is it a day off?

Each side of or is a full question. One True is enough.

day = "sunday"A box keeps the word sunday.
if day == "saturday" or day == "sunday":Is it saturday? False. Is it sunday? True. One True is enough.
print("no school!")The answer was True, so this path runs.
day = "monday"Now the box keeps monday.
if day == "saturday" or day == "sunday":Is it saturday? False. Is it sunday? False. Both are False, so or gives False.
print("no school!")Skipped. Time for school.
