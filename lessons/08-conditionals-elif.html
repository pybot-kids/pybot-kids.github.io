06CONDITIONALS · ELIF

One more question: elif.

elif is short for “else, if”. It asks a new question only when every question above it was False.

LOOK FIRST

A ladder of questions.

if

if asks first

The first question always goes with if.

elif

elif asks next

If the answer above was False, elif asks another question. You can add as many as you need.

else

else catches the rest

If every answer was False, the else path runs. It is optional.

STEP BY STEP

Follow the traffic light.

PyBot reads one question at a time, from the top.

light = "yellow"A box keeps the word yellow.
if light == "green":Is it green? No. Go down to the next question.
print("go")Skipped.
elif light == "yellow":Is it yellow? Yes!
print("slow down")This path runs.
elif light == "red":Not even asked. A path already ran.
print("stop")Skipped.
else:Skipped. else only runs when every answer was False.

LOOK FIRST

Three rules for elif.

1

The first yes wins

Python stops at the first True. The questions below it are not asked.

↕

Order matters

Put the hardest question first. score >= 9 goes before score >= 5.

2

Two ifs are two questions

With two separate ifs, both can run. With elif, only one path runs.
