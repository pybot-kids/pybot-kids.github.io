LOOK FIRST

A question with only two answers.

T/F

True or False

A Python question has only two answers: True or False. They start with a capital letter, like the yes-or-no box.

?

Compare two values

3 < 5 asks: is 3 less than 5? Python answers True.

==

One = or two?

One = puts a value in a box. Two == ask if two values are the same.

THE COMPARISON SIGNS

Six ways to compare.

SignIt asksExampleAnswer
==Are they the same?4 == 4True
!=Are they different?"cat" != "dog"True
<Is the left one smaller?7 < 2False
>Is the left one bigger?9 > 3True
<=Smaller, or the same?5 <= 5True
>=Bigger, or the same?6 >= 10False

A trick: < and > are like a hungry mouth. The open side always faces the bigger number.

JOIN QUESTIONS

and, or, not.

Sometimes one question is not enough. These three words help.

and

and: both must be True

sunny and warm is True only when sunny is True and warm is True.

or

or: one is enough

cake or ice_cream is True when at least one of them is True.

not

not: flip the answer

not True is False. not False is True.

has_ticket = TrueA yes-or-no box that keeps True.
is_tall = FalseAnother one that keeps False.
print(has_ticket and is_tall)and needs both. One is False, so it shows False.
print(has_ticket or is_tall)or needs just one. has_ticket is True, so it shows True.
print(not is_tall)not flips False into True.
age = 9A box keeps the number 9.
if age >= 8 and age <= 10:Is 9 >= 8? True. Is 9 <= 10? True. Both are True, so and gives True.
print("PyBot is for you!")The answer was True, so this path runs.
