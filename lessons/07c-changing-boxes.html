02CHANGE + MATH

A box can change.

A box can take its own value, change it, and keep the new one. That is how games count points.

USE THE OLD VALUE

Read the right side first.

score = score + 1 looks strange. Python first works out the right side: the old score plus 1. Then it puts the answer back in the same box.

score = 3→score = score + 1→
score4

3 + 1 is 4. Now the box keeps 4.

THE SHORT WAY

+= adds to the box.

+=

Add to it

score += 1 means the same as score = score + 1.

-=

Take away

lives -= 1 takes one life away from the box.

=

Start again

score = 0 throws the old value away and puts in 0.

MATH WITH BOXES

Boxes can do math together.

apples = 4 and pears = 3. Python opens both boxes and uses the numbers inside.

+

Add

apples + pears is 7.

-

Subtract

apples - pears is 1.

*

Multiply

apples * 2 is 8. The star means times.

/

Divide

apples / 2 is 2.0. Dividing always gives a decimal.

JOIN TEXT

+ glues text together.

name = "Ana". Then "Hi " + name makes "Hi Ana". Put a space inside the quotes, or the words stick together.

Watch out: "2" + "3" is "23", not 5. With quotes, Python glues text. Without quotes, 2 + 3 is 5.
