A NEW WORD

Your plans have a name: algorithms.

An algorithm is a list of clear steps, in order, that solves a problem. Every plan you just finished is an algorithm!

  • 1

    Clear steps

    Each step says exactly what to do. No guessing.

  • 2

    In order

    First, next, last. If you swap steps, the plan can break.

  • 3

    It finishes

    It stops when the job is done.

ALGORITHMS IN CODE

Code is an algorithm for a computer.

When you write code, you write the steps. The computer reads them one at a time, from top to bottom, and does exactly what each line says.

The computer never guesses. If a step is missing or in the wrong place, it will not fix it for you.
!
BIG IDEA

Order helps a plan work.

Clear steps in order make an algorithm. Computers follow algorithms one step at a time.
