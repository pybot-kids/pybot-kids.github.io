THE PLAN

The calculator in four steps.

Each step uses something you already know.

1

Ask two numbers

Turn each answer into a number. float keeps decimals like 2.5.

input + float

2

Ask the sign

The player types +, -, * or /. It stays text.

input

3

Choose the math

Compare the sign with == and do the matching operation.

if / elif / else

4

Pack it in a function

calculate gets the numbers and the sign and returns the answer. It checks for 0 first.

def + return
