THE TOOLBOX

Four tools for bug hunters.

🤖Be the computerFollow the code line by line and write down what each box keeps.
🕵️Spy with printAdd a print to peek inside a box while the code runs. Remove it when you are done.
🦆Explain it out loudTell a friend, a toy, or a rubber duck what each line does. Bugs pop out when you say them.
📝Write a bug reportSay what you did, what you expected, and what happened instead.
