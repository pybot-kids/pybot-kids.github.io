Python has no until

There is no until word in Python. Write while not, or while True with break.

while not full:pourpourpourfull!

WAY 1

while not: repeat until a box is True.

Read while not full as repeat until full.

full = FalseA yes-or-no box. The glass is not full yet.
cups = 0No cups poured yet.
while not full:Repeat until full. not False is True, so a turn starts.
cups = cups + 1Pour one more cup.
print("pour", cups)Shows pour 1, pour 2, pour 3.
if cups > 2:After the third cup, the glass is full...
full = True...so the box changes. not True is False, and the loop stops.
print("full!")Runs once, after the loop.

WAY 2

while True with break: stop from inside.

The loop would run forever, so you add a door out: break.

cups = 0No cups poured yet.
while True:True is always True, so on its own this loop never stops.
cups = cups + 1Pour one more cup.
print("pour", cups)Shows pour 1, pour 2, pour 3.
if cups > 2:Is the glass full now?
breakbreak means: leave the loop now. Python jumps to the first line after it.
print("full!")Runs once, after the loop.
