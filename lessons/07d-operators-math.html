03OPERATORS · MATH

Python is a super calculator.

An operator is a sign that does a job with two values. Python has seven math signs. Three are new: //, %, and **.

THE MATH SIGNS

Seven math signs.

SignIt doesExampleAnswer
+Adds7 + 29
-Takes away7 - 25
*Multiplies7 * 214
/Divides, with decimals7 / 23.5
//Divides, whole part only7 // 23
%Gives what is left over7 % 21
**Power: times itself7 ** 249

Remember: You met + - * / in Changing boxes. The new ones are // for the whole part, % for the leftover, and ** for power.

STEP BY STEP

Share the candies.

Python can tell how many each kid gets and how many are left.

candies = 77 candies.
kids = 22 kids.
each = candies // kids7 // 2 is 3. Each kid gets 3.
left = candies % kids7 % 2 is 1. One candy is left over.
print(each, left)Shows 3 1.
