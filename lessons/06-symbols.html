03PYTHON'S MARKS

Tiny marks have jobs.

A quote, colon, or bracket is not decoration. It gives Python a clue.

( )" "

We will meet them slowly. No memorizing today.

USE THESE SOON

Six marks to notice first.

" "

Quotes hold text

Words for people live between quotes: "hello".

( )

Parentheses hold what a command needs

print("hello") keeps the message inside them.

=

One equals stores a value

color = "orange" gives a value a name.

:

A colon opens a block

After if or for, it says: “the steps start here.”

#

A hash starts a note

Python ignores the note. It helps a person remember.

_

An underscore joins words

robot_color is one clear name without a space.

Meet four more. You do not need to use them yet.

[ ]

Brackets hold a list

A list keeps several items in order: ["moon", "star"].

{ }

Braces hold a collection

Later, Python can use them for labeled pairs or unique items.

/

A slash can divide

10 / 2 asks Python to divide ten into two parts.

\

A backslash changes the next mark

Inside text, \n means: start a new line.

Recognizing a mark is enough today. Its full lesson can wait.
