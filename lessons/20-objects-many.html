STEP BY STEP

Two robots, one mold.

The mold now has an action. Watch who self is each time.

class Robot:The mold.
def __init__(self, name):Setup: each new robot gets a name.
self.name = nameWrites it inside this robot.
def greet(self):An action for every robot. Its first word is always self.
print("Hi, I am", self.name)Uses this robot's own name.
bolt = Robot("Bolt")Robot number 1.
rita = Robot("Rita")Robot number 2, from the same mold.
bolt.greet()self is bolt. Shows: Hi, I am Bolt
rita.greet()self is rita. Shows: Hi, I am Rita
