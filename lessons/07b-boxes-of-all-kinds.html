05TYPES + LISTS

Every box keeps something.

Picture the computer's memory as a huge shelf full of little boxes. A variable is one box with a name label on it.

[ ]"hi"

I put things in labeled boxes so I never lose them.

WHAT GOES IN A BOX?

A box can keep different kinds of things.

9

Whole numbers

age = 9 keeps a number you can count and add.

1.3

Decimal numbers

height = 1.32 keeps a number with a point in it.

"a"

Text

name = "Ana" keeps letters. Text always goes between quotes.

✓

Yes or no

is_raining = True keeps True or False. Only two choices!

age9
height1.32
name"Ana"
is_rainingTrue

Four boxes, four labels. Python finds each value by its name.

A BOX CAN CHANGE

Put in something new, and the old thing leaves.

score = 0→score = 5→
score5

A box keeps one thing at a time. The newest value wins.

A BOX WITH SPACES INSIDE

A list keeps many things in order.

snacks = ["apple", "cookie", "grapes"] puts three things in one box, each in its own little space.

snacks=
  1. "apple"0
  2. "cookie"1
  3. "grapes"2

Python starts counting at 0. snacks[0] is the first space.

Fun fact: In math, a row of numbers in order, like [3, 1, 4], is called a vector. In Python, we make it with a list.

A SHELF OF ROWS

A matrix has rows and columns.

board = [[1, 2, 3], [4, 5, 6]] is a list of lists: two rows with three spaces each, like an egg carton.

board=
01201231456

board[1][0] means row 1, then space 0. That is 4.
