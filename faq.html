For learners

What is PyBot?

A free website where you learn Python, a real programming language, one small step at a time. It is made for kids from 8 to 10 years old, and it is fine up to about 12.

Do I need an account or a password?

No. There is no sign-up, no email, and no password. Just open PyBot and start.

Where do I start?

Open the learning path. It shows every zone like a race track. “CONTINUE HERE” marks your place, so you always know what comes next.

Open the learning path
Do I need to install Python?

No. Python runs right here in the browser. The first time you press Run Python, it needs internet and can take a little while. After that it is faster.

My code shows an error. Did I break something?

No! Errors are clues, not punishments. PyBot shows a short hint and the line to look at. Fix it and run again. If your code never stops, press Stop.

Can I learn in Spanish or English?

Yes. Press EN or ES at the top of any page. Your progress stays the same. Python words like print and if stay in English, because that is how Python is written.

Can I turn the sound off?

Yes. Press the ♪ button at the top of the page. PyBot remembers your choice.

Can I hide the little PyBot in the corner?

Yes. You can also drag PyBot to another spot, and it remembers where you left it. To hide it, press the PyBot button at the top of the page, or the × next to PyBot. Press the button again to bring PyBot back. On phones PyBot stays hidden so it does not cover the lesson.

What does “NEW · NOT DONE” mean on the map?

PyBot keeps growing. When a new page is added behind your place, the map marks it so you don't miss it. Visit it whenever you like.

For grown-ups

Where is the progress saved?

Only in this browser, on this device. PyBot has no server or database, so nothing about the learner's progress is stored online.

Can the progress get lost?

Yes, if the browser's data is cleared, if a private window is used, or if the learner switches to another browser or device. Save a backup file from time to time to be safe.

How do we move to another browser or device?

On the home page, press “Save a backup file”. Then open PyBot in the other browser and press “Load a backup file”. The file stays on your device; nothing is uploaded.

Go to the backup tools
Will an old backup still work after PyBot gets new lessons?

Yes. Older backups are updated to the newest PyBot when you load them, and the new lessons show up as pending. A backup from a newer PyBot can't be loaded into an older one.

What data does PyBot collect?

Only anonymous page-visit counts, with Google Analytics. Ads, ad personalization and Google signals are turned off. The learner's name, answers and progress are never sent. Google Analytics does set its own cookies.

Why does PyBot ask for a name?

So PyBot can greet the learner. It is optional, it stays in this browser, and it can be changed or forgotten at any time on the home page. A nickname works too.

How do we start over from zero?

At the bottom of the home page, an adults' section can erase all progress in this browser. It offers to save a backup first, because erasing can't be undone without one.

Which devices work?

Any up-to-date browser on a computer, tablet or phone. A computer with a keyboard makes writing code much easier.

Is PyBot free? Who makes it?

Yes, PyBot is free and has no ads. It is made with love in Colombia. If you want to help it grow, you can support it on Patreon, but it is never required.

What makes Python run inside PyBot?

Pyodide, a free, open-source project that runs real Python (CPython) in the browser with WebAssembly. It is why learners can code without installing anything. Thank you, Pyodide! PyBot is not affiliated with the project.

How can we support PyBot?

Press “♥ Support PyBot” at the top of any page to open PyBot's Patreon. Support helps make new lessons. It is always optional: every lesson stays free and ad-free for everyone.
