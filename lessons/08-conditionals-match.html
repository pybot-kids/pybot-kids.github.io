LOOK FIRST

switch in other languages, match in Python.

match

match looks at a box

match command: means: let us look at what is inside command.

case

case is one option

case "jump": runs its path when the box holds "jump".

_

case _ catches the rest

The _ means “anything else”. It works like else.

switch → match Heads up: Python has no switch word. Since Python 3.10, it uses match and case.

STEP BY STEP

Find the case that fits.

PyBot compares the box with each case, from the top.

day = "saturday"A box keeps the word saturday.
match day:Look inside the day box.
case "friday":Is it friday? No. Try the next case.
print("school")Skipped.
case "saturday":Is it saturday? Yes!
print("play")This path runs.
case _:Skipped. A case already fit.
print("rest")case _ runs only when no other case fits.

LOOK FIRST

Three rules for match.

1

Only one case runs

Python picks the first case that fits, then leaves the match.

_

case _ goes last

_ fits anything, so the cases below it would never get a turn.

|

| means or

case "saturday" | "sunday": fits both days with one path.
