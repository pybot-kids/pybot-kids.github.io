LOOK FIRST

The order Python follows.

1 ( )

Parentheses first

Whatever is inside ( ) is answered before anything else.

2 == in

Then compare and search

Comparisons like age > 8 and searches like "a" in word become True or False.

3 not

Then not

not flips the answer right next to it.

4 and · or

and, and last of all or

and goes before or. True or False and False is True, because False and False is done first.

A trick: When a question gets long, add ( ). Then you and Python read it the same way.
